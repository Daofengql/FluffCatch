## 系统边界

FluffCatch 是一个单管理员、自部署的兽聚返图收集与画廊应用。核心对象是“兽聚活动”，活动下包含公开或私密图片、待审核投稿、限时投稿链接、标签、点赞与存储引用。

系统分成三层：

- Go 后端：提供 API、认证、数据库访问、上传处理、缩略图与媒体访问控制。
- React 前端：提供公开站点、投稿入口、活动画廊和后台管理界面。
- MySQL 与对象存储：MySQL 保存元数据，对象存储保存原图、缩略图、Logo、背景图和封面。

## API 基本约定

- API 前缀统一为 `/api/v1`。
- 响应默认是 JSON。
- 错误响应格式为：

```json
{
  "error": "错误说明"
}
```

- 管理员接口需要登录后的 `fluffcatch_session` Cookie。
- 删除活动、删除待审核投稿、批量删除图片等高风险接口还需要验证码头：

```http
X-Captcha-Id: <captcha id>
X-Captcha-Answer: <captcha answer>
```

- 文件上传使用 `multipart/form-data`。
- 时间字段响应通常是 RFC3339 字符串；创建或更新活动时也接受 `YYYY-MM-DDTHH:mm`、`YYYY-MM-DD HH:mm:ss`、`YYYY-MM-DD` 等格式。

## 常见工作流

1. 管理员启动服务并执行数据库迁移。
2. 管理员创建活动，设置公开状态、投稿开关、地点、时间、私密图片访问口令和封面。
3. 管理员为活动生成限时投稿链接，可限制有效期、使用次数并绑定摄影师名称。
4. 访客通过投稿链接上传图片或视频，文件进入待审核池。
5. 管理员审核投稿，选择公开或私密可见性，通过后图片进入正式画廊。
6. 公开访客浏览活动、筛选图片、点赞、下载公开图片；输入私密口令后可临时访问该活动的私密图片。
