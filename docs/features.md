# 功能说明

本文档从产品行为角度说明 FluffCatch 当前已经实现的功能。接口级细节见 [API 参考](api.md)。

## 角色与权限

FluffCatch 面向单管理员自部署场景。

| 角色 | 能做什么 |
| --- | --- |
| 访客 | 浏览公开活动、查看公开图片、输入私密口令解锁活动私密图片、点赞公开图片、通过有效投稿链接上传文件。 |
| 管理员 | 登录后台，管理活动、封面、投稿链接、待审核投稿、正式画廊图片、站点设置、存储策略、上传限制、OIDC 绑定和维护扫描。 |

管理员认证使用 `fluffcatch_session` Cookie 和进程内会话。普通访客不需要账号。

## 公开站点

公开页面包括首页、活动详情页、统一投稿入口和登录页。

- `/`：活动列表首页。
- `/events/:id`：活动详情和图片画廊。
- `/submit`：统一投稿入口，可通过 URL 参数预填活动和投稿 token。
- `/login`：管理员登录入口。

首页展示公开活动，支持：

- 按关键字搜索活动标题。
- 按省份或城市筛选。
- 按日期范围筛选。
- 按开始时间倒序或升序排序。
- 分页加载。

站点名称、副标题、Logo、首页 Markdown、主题、页脚、联系组件、桌面和移动背景图都由后台站点设置控制。

## 活动管理

活动是系统的核心容器。每个活动包含：

- 标题。
- 简介。
- 详细地点。
- 省份和城市代码及名称。
- 开始时间和结束时间。
- 公开状态。
- 投稿开关。
- 封面图。
- 私密图片访问口令。
- 正式画廊图片数量。

活动公开状态影响访客侧可见性：

- `isPublic=true`：活动会出现在公开活动列表，访客可进入详情页。
- `isPublic=false`：活动只在后台可见；管理员仍可打开详情并管理图片。

投稿开关影响投稿链接：

- `submissionEnabled=true`：可以创建和使用投稿链接。
- `submissionEnabled=false`：投稿链接解析和投稿上传都会被视为不可用。

活动封面支持两种来源：

- 管理员上传一张封面图。
- 从活动内已有公开图片设置封面。

当前实现只允许公开图片被设为活动封面，避免私密图片内容通过封面泄露。

## 投稿链接

FluffCatch 当前使用“限时投稿链接”作为访客上传凭证，不再使用旧的活动投稿口令。

管理员可以为单个活动创建多个投稿链接。每个链接包含：

- 标签 `label`：用于管理员识别链接用途。
- 摄影师名 `photographerName`：可选。填写后，访客通过该链接上传的文件会自动使用这个摄影师名。
- 过期时间 `expiresAt`：由创建时的 `expiresInHours` 推导；为 `0` 表示不过期。
- 最大使用次数 `maxUses`：为 `0` 表示不限次数。
- 已使用次数 `useCount`。
- 撤销时间 `revokedAt`。

投稿链接只在创建时返回明文 `token`。之后列表接口只返回链接元数据，不再返回 token。

链接有效必须同时满足：

- 所属活动存在。
- 所属活动启用了投稿。
- token 匹配数据库中的 token hash。
- 链接未撤销。
- 链接未过期。
- 使用次数没有达到 `maxUses`。

上传时后端会在事务内锁定链接并递增 `use_count`，用于避免多个并发请求同时超出使用次数。

## 访客投稿

访客上传入口有两种：

- 活动详情页点击投稿，先输入投稿码或使用预带 token 的链接。
- `/submit?eventId=<id>&token=<token>` 统一投稿入口。

访客投稿要求：

- 必须提供有效 `submissionToken`。
- 文件字段可以是单文件 `file` 或多文件 `files`。
- 可填写摄影师名，除非链接已经绑定摄影师名。
- 可填写标签，标签会自动规范化为 `#标签`。
- 投稿不会立即进入正式画廊，而是进入待审核池，状态为 `pending`。

支持上传图片和视频：

- 图片大小上限由 `upload.maxFileSizeMb` 控制。
- 视频大小上限由 `upload.maxVideoSizeMb` 控制。
- 单批最多文件数由 `upload.maxFilesPerUpload` 控制，最大保护值是 200。
- 同时上传请求数由 `upload.maxConcurrentUploads` 控制，后端硬上限是 8。

前端会根据投稿链接剩余次数限制本次可选文件数量；后端仍会做最终校验。

## 管理员直接上传

管理员登录状态下调用同一个投稿上传接口时，不需要投稿链接：

- 上传结果直接创建正式画廊图片。
- 不进入待审核池。
- 可以设置图片可见性。

这让管理员可以在活动详情页补充正式图片。

## 投稿审核

待审核投稿包含：

- 原始文件 URL。
- 缩略图 URL。
- 摄影师名。
- 标签。
- 内容类型。
- 文件大小。
- EXIF 信息。
- 拍摄时间。
- 创建时间。

管理员可以：

- 查看所有待审核投稿。
- 查看某个活动下的待审核投稿。
- 批量通过投稿。
- 批量删除投稿。

批量通过时可指定可见性：

- `public`：进入公开画廊。
- `private`：进入私密画廊。

批量删除投稿需要验证码头，防止误操作。

## 正式画廊

活动详情页展示正式图片。图片对象包含：

- 原图 URL。
- 缩略图 URL。
- 访问状态。
- 内容哈希。
- MIME 类型。
- 文件大小。
- 点赞数。
- 当前访客是否已点赞。
- 摄影师名。
- 可见性。
- 标签。
- EXIF。
- 拍摄时间。
- 创建和更新时间。

画廊支持筛选和排序：

- 可见性：全部、公开、私密。
- 标签。
- 摄影师。
- 媒体类型：图片或视频。
- 排序：最新、最旧、拍摄时间降序、拍摄时间升序、点赞数。
- 分页。

管理员可以：

- 修改单张图片的摄影师名、可见性、标签、拍摄时间。
- 删除单张图片。
- 批量删除图片。
- 批量修改图片可见性、摄影师名和标签。
- 从公开图片设置活动封面。

## 私密图片访问

图片可见性分为：

- `public`：公开可见。
- `private`：需要活动私密口令解锁。

私密图片的访问规则：

- 管理员始终可以访问。
- 访客默认只能看到私密图片的受限状态，缩略图会走受控媒体接口。
- 访客输入活动私密口令后，后端设置 `fluffcatch_private_<eventId>` Cookie。
- 私密访问 Cookie 有效期是 24 小时。
- Cookie 使用 `auth.session_secret` 签名；如果未配置，开发环境会使用内置开发默认值。

活动编辑时可以设置、修改或清除私密图片访问口令。

## 点赞

访客可以点赞公开图片。

点赞规则：

- 只允许点赞公开活动里的公开图片。
- 后端基于访客标识生成哈希，避免重复点赞。
- 不保存原始 IP。
- 重复点赞会返回当前点赞状态，不会重复增加计数。

## 下载

前端支持单张下载和批量打包下载。

- 公开图片通常直接访问对象 URL。
- 私密图片通过 `/media/photos/:id/:variant` 受控接口访问。
- 下载失败会显示独立错误，不会中断整个活动详情页。
- 批量下载会拉取每个文件并在浏览器里生成 ZIP。

## 站点设置

后台站点设置包括：

- 站点名称。
- 副标题。
- 首页 Markdown。
- 主题模式：系统、浅色、深色。
- 主题预设和自定义主色。
- Logo。
- 桌面背景图。
- 移动背景图。
- 页脚区块。
- 联系组件标题和 HTML。

Logo 和背景图通过后台上传。背景图会被处理为：

- 桌面：`1920x1080` JPEG。
- 移动：`1080x1920` JPEG。

站点资产会保存到当前活动存储策略，并在替换或清除时尝试删除旧对象。

## 存储策略

系统支持多存储策略。每个对象都会记录 `storage_policy_id` 和对象 key，因此更换默认存储策略不会破坏旧文件读取。

支持的驱动包括：

- `local`
- `s3`
- `minio`
- `aws-s3`
- `aliyun-oss`
- `tencent-cos`
- `cf-r2`

本地存储通过 `/media/:policyID/*key` 提供文件。外部 S3 兼容存储通常应配置公开桶、反向代理或 CDN 的 `publicBaseUrl`，让前端直接访问对象 URL。

后台设置页可以：

- 查看存储策略列表。
- 修改当前默认策略。
- 测试单个策略连接。
- 查看每个策略引用对象数量和占用空间。

仍有文件引用的存储策略不应删除，否则旧文件会无法读取。

## 维护扫描

后台提供两个只读维护扫描接口：

- 孤儿本地对象扫描：扫描本地存储中没有数据库引用的文件。
- 缺失缩略图扫描：扫描图片类型但没有缩略图 key 的正式图片和投稿。

孤儿扫描只处理 `local` 策略，外部对象存储会跳过。

## OIDC 登录和绑定

OIDC 用于管理员登录补充认证，目前配置从 `config.yaml` 或环境变量读取。

功能包括：

- 公开查询 OIDC 是否启用和提供商名称。
- 获取 OIDC 登录跳转 URL。
- 管理员登录后绑定 OIDC subject。
- 查询绑定状态。
- 解绑 OIDC subject。

回调接口会根据流程类型重定向回登录页或后台设置页，并附带成功或错误 query 参数。

## 安全和限制

当前实现包含这些安全边界：

- 管理员密码使用哈希保存。
- 登录需要验证码。
- 高风险删除操作需要额外验证码头。
- 管理员会话保存在后端进程内存中，服务重启后会失效。
- 私密图片访问通过签名 Cookie 控制。
- 投稿 token 只保存 hash。
- 上传有单文件、批量请求体、单批文件数、并发数限制。
- JSON 请求启用未知字段拒绝，避免客户端误传字段被静默忽略。
